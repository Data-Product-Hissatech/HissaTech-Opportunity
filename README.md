# HissaTech Opportunity 

نظام آلي لجمع وتحليل إعلانات العقارات من sa.aqar.fm ، لدعم قرارات الاستثمار. يغطي سحب إعلانات البيع يوميًا، وكشف العقارات المؤجّرة والمعلنين المباشرين بدون أي تكلفة API، وكشف الشذوذ، وحساب العائد، وتقارير الاستثمار.

## التغطية

| المنطقة | المدن |
|---|---|
| الوسطى | الرياض، القصيم |
| الغربية | جدة، مكة، المدينة المنورة، الطائف |
| الشرقية | الدمام، الخبر، الظهران، الجبيل، الأحساء، القطيف |
| الجنوبية | جازان، خميس مشيط، أبها |

أنواع العقارات: شقق، فلل، أدوار، أراضي، عمائر، مكاتب (وملاحق/مستودعات/مصانع/محلات حسب المدينة).

## خطوات النظام (Pipeline)

1. **السحب**: سكرابرات لكل مدينة ونوع (matrix حسب المدينة × النوع × الجزء). تستخرج البيانات من JSON الصفحة (`self.__next_f.push`).
2. **التنظيف**: إزالة الشذوذ حسب نوع العقار (`clean_property_types.py`، IsolationForest).
3. **كشف المؤجّر**: استخراج الإيجار السنوي من وصف الإعلان بـ regex بدون API، مع فحص منطقية الرقم وتحديد المعلن المباشر (المالك).
4. **العائد والتقارير**: نموذج العائد، التقييم النهائي، وتقارير الاستثمار.
5. **قرار حصتك**: PROCEED / REVIEW / REJECT.
